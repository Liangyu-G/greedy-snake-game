# Greedy Snake Game

一个简单的网页版贪吃蛇游戏，使用 HTML、CSS 和 JavaScript 编写。

## 功能

- 使用方向键或 WASD 控制蛇移动
- 吃到食物后增加分数
- 自动记录本地最高分
- 支持暂停和重新开始
- 撞墙或撞到自己时游戏结束

## 在线访问

如已部署，可通过以下地址访问：

- http://snake.atri-heart.vip:18080

> 若无法打开，请先确认部署服务、端口映射、防火墙和域名解析是否正常。

## 运行方式

直接在浏览器中打开 `index.html` 即可开始游戏。

也可以使用任意静态服务器运行，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 部署说明

本项目是纯静态页面，不需要后端服务。可使用 Nginx、Caddy、GitHub Pages 或任意静态文件服务部署。

示例：将仓库文件放到静态站点目录后，确保入口文件为 `index.html`，并开放对应访问端口（例如 `18080`）。

## 移动端支持说明

页面已包含响应式布局，画布会随屏幕宽度缩放。但当前游戏主要依赖键盘方向键或 WASD 操作，移动端触控方向键/滑动控制仍待补充。
