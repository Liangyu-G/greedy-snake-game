# Greedy Snake Game

一个简单的网页版贪吃蛇游戏，使用 HTML、CSS 和 JavaScript 编写。

## 功能

- 使用方向键或 WASD 控制蛇移动
- 吃到食物后增加分数
- 自动记录本地最高分
- 支持暂停和重新开始
- 撞墙或撞到自己时游戏结束

## 文件结构

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## 运行方式

直接在浏览器中打开 `index.html` 即可开始游戏。

也可以使用任意静态服务器运行，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
